# Travel plan application

## Tech

- API using python 
- UI using Reactjs with shadecd
- UI design for mobile first
- Database using mongodb 
- Use Docker compose 
- Auth using firebase 

## Features

- Login page 
- Signup page 
- Signup with Google, Facebook
- Left menu for navigation
- Map page for showing google map integration 
- Plan list page 
- Plan detail page 
- Click on plan item on list page => redirect to detail page 
- Plan includes fields: name, description, author, total travel distance, photo url, total spent money
- Plan item includes: name, author, planId, planned stopped time, stopped time, order in plan, location on google map, spent money, photo url 
- Photo uploading
